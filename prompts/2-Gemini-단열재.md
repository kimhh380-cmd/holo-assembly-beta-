## 첫 메시지 (아래 줄부터 끝까지 복사)

---

나는 고등학생이고, 로켓 부품을 카드로 만들어 홀로그램 위에서 조립하고 시험하는 웹 앱 “홀로그램 기체 조립대”를 Claude, ChatGPT, Grok과 나눠서 만들고 있어. 너는 **단열재(열 보호) 실험** 담당이야.
첨부한 AGENTS.md(안내서), docs/api.md(확장 API), docs/physics.md(지금의 플라즈마 시험 공식)를 끝까지 읽어 줘. js/01-data.js에는 지금의 단열재 카드 7종이 있고, js/04-physics.js의 plasmaSim이 지금의 열전도 계산이야.

**네가 만들 것: `js/ext/insulation-lab.js` 한 파일**
1. **단열재 카드 설계**
   - 설계 패널(registerPanel)에서 여러 층을 쌓아 내 단열재를 만들 수 있게 해 줘. 예: 바깥 세라믹 타일 30 mm + 안쪽 담요 10 mm + 접착층.
   - 층마다 재료와 두께를 고르고, 비율(%)도 볼 수 있게 해 줘.
   - 만든 단열재는 `HOLO.saveCustomCard({ cat:'tp', kind:'tps', ... })`로 카드로 저장해 줘. 카드 필드는 docs/api.md 2장을 따라 줘. 여러 층 정보는 `layers` 같은 필드를 더 붙여 저장하면 돼.
   - 새 단열재 재료가 필요하면 `registerCard`로 추가해 줘. id는 `tp_`로 시작해 줘.
2. **단열재 시험**
   - 지금 플라즈마 시험은 단열재를 한 층으로만 계산해. `plasma`를 같은 id로 다시 등록해서 **여러 층을 계산하는 시험**으로 바꿔 줘.
   - 새 시험도 만들어 줘(id는 `tp_`로 시작). 예:
     - 극저온 증발 시험: 탱크 단열재가 액체산소·메탄·수소를 얼마나 끓게 하는지
     - 열진공 반복 시험: 우주의 햇빛·그늘 온도 변화를 반복
     - 타일 접착·진동 시험
   - 홀로그램에서 온도가 색으로 보이고, 층별 온도와 깎이는 두께가 계기판(hud)에 나오게 해 줘. 실패하면 타일이 떨어지거나 타는 연출을 넣어 줘.
3. 설명과 결과 문장은 고등학생이 이해할 수 있는 쉬운 한국어로 써 줘. 재료 성질 값에는 “대표값(약)”이라고 출처나 근거를 문서에 적어 줘.

**규칙**
- 핵심 파일(css/style.css, js/01~12, js/99)은 고치지 마. API가 부족하면 지어내지 말고 “필요한 API” 목록으로 알려 줘.
- 순수 JavaScript로 만들고 외부 라이브러리는 쓰지 마. 파일 전체를 (() => { ... })(); 로 감싸 줘.
- 내 저장 키는 `insulation`, 시험 설정(cfg) 키는 `tp_`로 시작해 줘. CSS가 필요하면 모듈 안에서 <style>을 넣고, 클래스 이름은 `x-insulation-`으로 시작해 줘.

**결과로 줄 것**
1. `js/ext/insulation-lab.js` 전체
2. `docs/ext-insulation.md`: 재료 값, 열전도 계산 방법, 시험 기준
3. index.html에 넣을 한 줄
4. AGENTS.md CHANGELOG에 넣을 한 줄
5. 필요한 API 목록 (있으면)

코드부터 쓰지 말고, **먼저 화면 구성과 계산 방법 계획을 짧게 보여 줘.** 내가 괜찮다고 하면 그때 코드를 써 줘.
