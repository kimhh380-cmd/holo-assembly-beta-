## A. 첫 메시지 — 엔진 기능 (아래 줄부터 끝까지 복사)

---

나는 고등학생이고, 로켓 부품을 카드로 만들어 홀로그램 위에서 조립하고 시험하는 웹 앱 “홀로그램 기체 조립대”를 Claude, ChatGPT, Gemini와 나눠서 만들고 있어. 너는 **엔진** 담당이야.
첨부한 AGENTS.md(안내서), docs/api.md(확장 API)를 끝까지 읽어 줘. js/01-data.js에 지금의 엔진 카드 8종(랩터, 멀린, RS-25 등)이 있고, js/08-render.js의 drawEngines가 엔진 노즐을 그려.

**네가 만들 것: `js/ext/engine-lab.js` 한 파일**
1. **엔진 설계**
   - 설계 패널(registerPanel)에서 엔진을 직접 설계할 수 있게 해 줘. 이 패널은 역할이 엔진부(engbay)인 부품에서 보이면 돼.
   - 정할 값: 추진제, 엔진 사이클(가스 발생기·다단 연소·전유량·익스팬더), 연소실 압력, 노즐 팽창비, 목 지름, 혼합비 등.
   - 위 값으로 추력, 해수면·진공 비추력(Isp), 질량을 로켓 방정식 수준의 공식으로 계산해 보여 줘.
   - 만든 엔진은 `HOLO.saveCustomCard({ cat:'en', kind:'engine', fuel, noz, m, vac, ... })`로 카드로 저장해 줘. 필드는 docs/api.md 2장을 따라 줘. 설계값은 더 붙여도 돼.
   - 저장한 엔진은 엔진부에 바로 달 수 있어야 해.
2. **엔진 시험**: `registerTest`, id는 `en_`로 시작하고 `cat:'engine'`, `applies`는 엔진이 달린 엔진부에만.
   - 연소 시험(핫파이어): 점화 → 정격 → 종료. 시간에 따른 추력과 연소실 압력이 계기판에 나오게 해 줘.
   - 그 밖의 예: 짐벌 시험, 노즐 냉각 시험, 연소 불안정(진동) 시험.
   - 홀로그램에 배기 불꽃(플룸), 충격파 다이아몬드, 시험대가 보이게 rig로 그려 줘.
   - 실패하면 노즐이 타거나 연소실이 터지는 연출을 넣어 줘.
3. **기능 구현 과정 설명**: `docs/ext-engine.md`에 엔진을 어떤 순서와 원리로 구현했는지, 시험은 실제 엔진 개발의 어떤 시험을 본떴는지 고등학생이 이해할 수 있게 써 줘.
4. **이미지 연결**: 카드에 `img: 'assets/cards/<카드id>.png'`를 넣어 줘. 이미지 파일은 따로 만들 거야.

**규칙**
- 핵심 파일(css/style.css, js/01~12, js/99)은 고치지 마. API가 부족하면 지어내지 말고 “필요한 API” 목록으로 알려 줘.
- 순수 JavaScript로 만들고 외부 라이브러리는 쓰지 마. 파일 전체를 (() => { ... })(); 로 감싸 줘.
- 내 저장 키는 `engine`, 카드·시험 id와 설정(cfg) 키는 `en_`로 시작해 줘.

**결과로 줄 것**
1. `js/ext/engine-lab.js` 전체
2. `docs/ext-engine.md`
3. index.html에 넣을 한 줄
4. AGENTS.md CHANGELOG에 넣을 한 줄
5. 필요한 API 목록 (있으면)

코드부터 쓰지 말고, **먼저 계획을 짧게 보여 줘.** 내가 괜찮다고 하면 그때 코드를 써 줘.
