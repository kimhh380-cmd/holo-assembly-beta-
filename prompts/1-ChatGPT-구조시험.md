# ChatGPT 지시서 — 구조 시험을 시뮬레이션으로

## 올릴 파일
가능하면 **zip 파일 하나**(holo-assembly-project.zip)를 올리세요. ChatGPT는 zip을 풀어서 읽을 수 있어요.
zip이 안 되면 아래 파일만 올리세요.
- `AGENTS.md`, `docs/api.md`, `docs/physics.md`
- `js/ext/_template.js`
- 참고용: `js/04-physics.js`, `js/09-test-fx.js`, `js/01-data.js`

## 첫 메시지 (아래 줄부터 끝까지 복사)

---

나는 고등학생이고, 로켓 부품을 카드로 만들어 홀로그램 위에서 조립하고 시험하는 웹 앱 “홀로그램 기체 조립대”를 Claude, Gemini, Grok과 나눠서 만들고 있어. 너는 **구조 시험** 담당이야.
첨부한 AGENTS.md(안내서), docs/api.md(확장 API), docs/physics.md(지금의 시험 공식)를 끝까지 읽어 줘. js/04-physics.js와 js/09-test-fx.js는 지금 시험이 어떻게 돌아가는지 보여 주는 참고용이야.

**네가 만들 것: `js/ext/structure-lab.js` 한 파일**
지금 압력·압축·굽힘·진동 시험은 공식에 값을 넣어 한 번에 답을 내고, 애니메이션은 그 답을 보여 주기만 해. 이걸 **실제로 시뮬레이션을 돌리는 시험**으로 바꿔 줘.
- 시간에 따라 하중을 올리면서 변형과 응력을 단계별로 계산하는 방식이면 좋겠어. 예: 벽을 고리·띠 요소로 나눈 간단한 유한요소, 초기 결함이 있는 좌굴, 하중-변위 곡선, 소성 변형 후 파단.
- 계산 결과가 홀로그램 변형(deform)과 시험 장비(rig)에 그대로 보여야 해. 예: 응력이 큰 곳만 색이 바뀜, 좌굴 주름이 생기는 위치와 모양이 계산 결과대로 나옴.
- 기본 시험을 대체할 때는 같은 id로 registerTest 해 줘(`press`, `comp`, `bend`, `vib`). 새 시험을 더한다면 id를 `st_`로 시작해 줘. 예: 비틀림, 낙하 충격, 반복 하중 피로.
- 재질(part.mat), 벽 두께(part.t), 구조 방식(part.build), 모양(part.shape)이 결과에 제대로 반영돼야 해.
- 고등학생이 원리를 이해할 수 있게, 시험 설명(desc)과 결과 문장(sum, detail)은 쉬운 한국어로 써 줘.
- 계산이 무거우면 시험 시작 때 미리 다 계산해 두고, 애니메이션은 tau로 결과를 재생하는 방식으로 해 줘. 화면이 멈추면 안 돼.

**규칙**
- 핵심 파일(css/style.css, js/01~12, js/99)은 고치지 마. API가 부족하면 지어내지 말고 “필요한 API” 목록으로 알려 줘.
- 순수 JavaScript로 만들고 외부 라이브러리는 쓰지 마. 파일 전체를 (() => { ... })(); 로 감싸 줘.
- 내 저장 키는 `structure`, 시험 설정(cfg) 키는 `st_`로 시작해 줘.

**결과로 줄 것**
1. `js/ext/structure-lab.js` 전체
2. `docs/ext-structure.md`: 쓴 모델과 공식, 가정, 한계
3. index.html에 넣을 한 줄
4. AGENTS.md CHANGELOG에 넣을 한 줄
5. 필요한 API 목록 (있으면)

코드부터 쓰지 말고, **먼저 어떤 시뮬레이션 방식으로 할지 계획을 짧게 보여 줘.** 내가 괜찮다고 하면 그때 코드를 써 줘.

- 너무 복잡하면: “고등학생도 이해할 수 있게 계산을 줄이고, 설명을 더 쉽게 바꿔 줘.”
