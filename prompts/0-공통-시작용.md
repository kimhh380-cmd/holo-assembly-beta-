# 아무 AI에게나 쓸 수 있는 공통 시작 글

GPT·Gemini·Grok에게는 각자의 지시서(1~3번 파일)를 쓰세요. 이 파일은 그 밖의 AI에게 작은 일을 맡길 때 씁니다.
아래 줄부터 끝까지 복사해서 붙여 넣으세요. 마지막 줄의 [ ]는 하고 싶은 일로 바꾸세요.

---

나는 고등학생이고, 로켓 부품을 카드로 만들어 홀로그램 위에서 조립하고 시험하는 웹 앱 “홀로그램 기체 조립대”를 여러 AI와 함께 만들고 있어.
첨부한 AGENTS.md(프로젝트 안내서)와 docs/api.md(확장 모듈 API)를 끝까지 읽고 다음 규칙을 지켜 줘.

- 핵심 파일(css/style.css, js/01~12, js/99)은 고치지 않는다. 새 기능은 js/ext/ 안에 새 파일 하나로 만들고, HOLO API로 등록한다.
- 빌드 도구·외부 라이브러리·import 없이 순수 JavaScript로 만든다. 모듈 전체를 (() => { ... })(); 로 감싼다.
- UI 문구는 한국어로 쓰고, 어두운 홀로그램 디자인(청록 #3ff0ff, 호박색 #ffc24a)을 맞춘다.
- 첨부 파일에 실제로 있는 함수와 HOLO API만 쓴다. API가 부족하면 지어내지 말고 “필요한 API” 목록으로 알려 준다.
- 결과로 다섯 가지를 줘: ① 모듈 파일 전체 ② 설명 문서 ③ index.html에 넣을 한 줄 ④ AGENTS.md CHANGELOG에 넣을 한 줄 ⑤ 필요한 API 목록(있으면).
